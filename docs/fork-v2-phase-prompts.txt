【关键背景（方案文档里有，这里再强调一次，做错会毁数据）】
- 转换器 document_converter.py 只读 format_config.section_order，**不读 hidden_sections**。
  也就是说：库里有 12 条记录的 format_config.hidden_sections 现在完全不生效，
  那些"被隐藏"的板块其实一直显示在纸面上。
  你的迁移会让它们第一次真正生效 —— 这是修复，不是 bug，但它是**用户可见的变化**。
  所以 dry-run 必须逐条列出 "哪条记录的哪些板块会从纸面上消失"（visibility_changes 字段），
  我要人工看一眼才能让你 apply。
- 每个 Phase 1 脚本文件头必须有 sys.path 引导，否则 import app.xxx 会失败：
    from pathlib import Path
    import sys
    BACKEND = Path(__file__).resolve().parents[1] / "backend"
    sys.path.insert(0, str(BACKEND))
- 旧版式键的消费顺序不能错：先用 section_order 排序 → 再消费 hidden_sections → 最后删两个键。
  顺序反了会丢信息。
